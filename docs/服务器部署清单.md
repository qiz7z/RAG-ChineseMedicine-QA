## 一、上传什么（重要：别漏 src/config.py）

⚠️ **`.gitignore` 忽略了 `src/config.py` 和 `.env`**。如果你用 `git clone`，
服务器上会缺这两个文件，直接跑不起来。**必须单独补传。**

### 推荐方式：打 tar 包上传（一次搞定，绕开 gitignore）

在**本机** Git Bash 里执行：

```bash
cd /c/Users/liuqi/Desktop/Chinese-Medicine

# 打包：代码 + 数据 + 评测集 + 配置（排除缓存/大索引/模型权重）
tar -czf /tmp/cm_upload.tar.gz \
  --exclude='__pycache__' --exclude='*.pyc' \
  --exclude='data/vectorstore' \
  --exclude='models/bge-large-zh-v1.5/model.safetensors' \
  --exclude='.workbuddy/tmp' \
  src langchain_app scripts tests docs data/processed data/eval \
  models requirements.txt requirements-langchain.txt README.md 项目书.md \
  .env

# 看体积（预期 ~45M）
ls -lh /tmp/cm_upload.tar.gz
```

然后传到服务器（会要一次密码，或用你已配好的密钥）：

```bash
scp /tmp/cm_upload.tar.gz shp@10.119.5.234:~/
```

### 为什么排除这三样

| 排除项 | 体积 | 原因 |
|---|---|---|
| `data/vectorstore/` | 175M | **服务器重建**，避免跨平台二进制差异（FAISS/pickle） |
| `model.safetensors` | 1.3G | 嵌入模型权重，看服务器有没有再决定传不传 |
| `__pycache__` | — | 跨平台/sys.path 污染，务必排除 |

### 服务器上解包

```bash
ssh shp@10.119.5.234
mkdir -p ~/chinese-medicine && cd ~/chinese-medicine
tar -xzf ~/cm_upload.tar.gz
ls -la          # 确认 src/config.py 和 .env 在
```

## 三、改配置（服务器路径与 Windows 不同）

编辑 `~/chinese-medicine/src/config.py` 和 `langchain_app/config.py`，确认模型路径：


## 四、跑起来（三个命令）

```bash
cd ~/chinese-medicine

# 4.1 环境
python3 -m venv .venv && source .venv/bin/activate
pip install -U pip wheel
pip install torch sentence-transformers "rank-bm25" jieba numpy openai python-dotenv pytest
pip install faiss-gpu || pip install faiss-cpu
pip install langchain==1.3.9 langchain-openai==1.3.2 \
            langchain-huggingface==1.2.2 langchain-community==0.4.2 \
            langchain-classic          # ← 原 requirements 漏声明，必须补

# 4.2 重建索引（两套，各 ~2-5 分钟）
python scripts/build/build_index.py            # 主项目（FAISS+BM25+SQLite）
python scripts/build/build_index_lc.py         # LangChain 标准版

# 4.3 确认判分口径没漂（24 项应全绿）
python -m pytest tests/test_eval_criteria.py -q

# 4.4 跑 4 组评测
python scripts/run/run_eval.py --mode retrieval --no-rerank   # src 关重排
python scripts/run/run_eval.py --mode retrieval               # src 开重排
python scripts/run/run_eval_lc.py --no-rerank                 # lc 关重排
python scripts/run/run_eval_lc.py                             # lc 开重排

# 报告落在 data/eval/reports/
ls -lt data/eval/reports/ | head
```

> 显存紧张时前面加 `RAG_DEVICE=cpu`（本次新加的环境变量）。

## 五、预期结果（用来校验跑对了没）

| 引擎 | loose Hit@5 | strict Hit@5 |
|---|---|---|
| src 开重排 | **89.0%** | **82.0%** |
| lc 关重排 | **94.0%** | 待测（本机那次配置不对等，作废） |

**关键校验点**：`src 开重排` 跑出来必须复现 **89.0% / 82.0%**。
对得上说明服务器环境与本机一致，数据可信；对不上说明索引重建或依赖版本有差异，要先排查。
