# 10 · OCR 药品名与异体字纠错

> 2026-09-22（第三篇）。接 [docs/08](08_检索缺陷修复与口径澄清.md)、[docs/09](09_ETL串块与条目丢失修复.md)。
> 目标：让用户用**正确的药名**能搜到东西。本次共修正 **167 个药品名**（首批 127 + 复查批 40），
> 并纠正正文中一批高频错字；另修掉药名清洗的两个系统性缺陷（`<w:tab/>`、规则键与清洗顺序错配）。
>
> **本文两处数字要注意区分**：第一节的表格是**首批 127 个**的盘点；
> 第六节末的「复查批」是后来用第二个独立信号又找出的 40 个。合计 167。

---

## 一、为什么这个比前两项更值得做

前几项缺陷（分类值、章节召回、串块）**指标测不出来**（0/106、1/106、±1pp）。
OCR 药名不一样——它**直接决定检索能不能命中**：

| 用户输入 | 索引里的名字（修复前） | 结果 |
|---|---|---|
| 川芎 | `川B` | 搜不到 |
| 栀子 / 茵栀黄口服液 | `梔子` / `茵梔黄口服液` | **搜不到**（正文里 `梔` 出现 **8,892 次**） |
| 马齿苋 | `马齿免` | 搜不到 |
| 豨薟草 | `豬签草` | 搜不到 |
| 淫羊藿 | `淫羊蕾` | 搜不到 |
| 开胸顺气丸 | `幵胸顺气丸` | 搜不到 |

修完后实测：**loose Hit@5 +1.89pp、strict Hit@1 +15.79pp**（见第五节）。

## 二、检测方法（关键：不要靠猜）

原实现是一张 8 条的手工白名单（`DRUG_NAME_OCR_FIXES`），且 `CHAR_OCR_FIXES`
定义了却没被 `clean_text` 调用。本次用三步把问题**查全**：

### 第 1 步：字符频次法（粗筛，假阳性高）

药名里出现的汉字，若在**全文正文中几乎不出现**，高度可疑——真药名必然在正文反复出现。

结果：77 个可疑字符。但假阳性约一半（`华佗再造丸`、`娑罗子`、`柿蒂`、
`黄蜀葵花`、`黄芩` 等合法名也命中，因为它们只被命名一次）。

### 第 2 步：拼音/拉丁名互证（定性）

每个条目自带 `pinyin_name` 与 `latin_name`，OCR 认错汉字时拼音往往仍是**正确**的：

```
川B        拼音 Chuanxiong            → 川芎
马齿免      拼音 Machixian / PORTULACAE HERBA  → 马齿苋
椅藤子      概述 Ketengzi / ENTADAE SEMEN      → 榼藤子
青曝石      拼音 Qingmengshi          → 青礞石
锗签草      正文「豬」30 次全是「豨」，Siegesbeckia → 豨薟草
```

（注：`pinyin_name` 字段本身也不完全可靠——很多条目只存了剂型末音节如 `plan`/`wan`，
故只用它做**定性证据**，不做自动判定。）

### 第 3 步：`zhconv` 查异体字回流（互补）

用 `zhconv` 把药名转简体，有差异的即含繁体/异体字。查出 **43 个**，其中影响最大的是
`梔`（正文 8,892 次）。

> ⚠️ **不要用 zhconv 整库转繁简**：`癥` 在《药典》里是**正确**用法
> （化癥回生片、止痛化癥片），整库转换会把它错改成「症」。

## 三、最关键的一条：药名层与正文层必须分开

同一个错字在**药名**与**正文**里的合法性完全不同。全库统计后：

| 错字 | 药名中 | 正文中 | 结论 |
|------|--------|--------|------|
| 茂 | 只会是「芪」的误认（19 个药名） | **合法**：140 次「叶茂盛时采收」 | 药名可整字替换，正文不可 |
| 苔 | 只会是「芩」的误认 | **合法**：80 次「苦苣苔科」 | 同上 |
| 蕾 | 只会是「藿」的误认 | **合法**：575 次「干燥花蕾」 | 同上 |
| 萼 | 只会是「芎」的误认 | **合法**：666 次「萼筒」「萼片」 | 同上 |
| 替 | — | **合法**：11 次「被替代对照品」 | 一律不做整字替换 |
| 幵 / 矶 / 苜 | 误认 | 正文亦从不合法 | 两层都可整字替换 |

于是 `cleaner.py` 分成两层：

- `DRUG_NAME_OCR_FIXES`（子串级，先执行）+ `DRUG_NAME_CHAR_FIXES`（整字级，后执行）
  → 只作用于 `drug_name` / `parent_drug`
- `CONTEXT_FIXES`（正文级）→ 只做**词组级**替换（如「川萼」「蕾香」「菌麻」），
  外加 3 个经核对在正文亦不合法的整字规则

**顺序敏感**：`'总苔'→'总苷'` 必须先于整字规则 `'苔'→'芩'`，否则
「积雪草总苔」会变成「积雪草总芩」。

## 四、踩过的三个坑（都已在测试里固化）

### 坑 1：整字替换「醍 → 滤」是错的
`醍` 是**多义**的：`乙醍` = 乙醚（1485 次）、`油醍` = 石油醚（695 次）、
`蔥醍` = 蒽醌（41 次）。
按整字替换后，「合并**乙醍**液」被改成了「合并乙滤液」——**正确是乙醚液**。
→ 改为词组规则：`乙醍→乙醚`、`油醍→油醚`、`蒽[醍酿醞酝]→蒽醌`。

### 坑 2：整字替换「豬 → 猪」是错的
正文里 30 次「豬」**全部**是「豨」（豨薟草 / 豨桐），而「猪」另正确出现 303 次。
→ 改为 `豬→豨`。

### 坑 3：整字替换「蔥 → 葱」是错的
55 次**全部**是「蒽」（总蒽醌 / 游离蒽醌），不是「葱」。
→ 改为 `蔥→蒽`。

> 三个坑的共同教训：**「这个字看起来像 OCR 错」不等于「它只有一个正确写法」**。
> 必须先看全库上下文分布再决定替换粒度。

## 六、连带的排序问题：药名精确度作为次级排序键

修名之后出现一个**副作用**：`炙黄芷` 被正确改为 `炙黄芪` 后，它成为合法条目；
而查询药名的扩展是**子串**方向，于是「问黄芪」时候选池里多了 `炙黄芪`，
把 `黄芪-饮片` 从第 1 位挤到第 3~5 位，**8 道黄芪相关题的 strict@1 一起下降**。

这不是回归，而是暴露了一个排序原则缺失：**问「黄芪」时，含黄芪的成药不该压过黄芪本身**。
strict 口径本来就只认「该药本身 + 其饮片」，排序应对齐。

修法：章节提升的排序键从 `(章节命中数)` 改为 **`(章节命中数, 药名贴合度)`**，
其中贴合度 2 = 该药本身或其饮片、1 = 含该药名的其他制剂、0 = 无关
（`_name_exactness`，两套引擎同口径）。

效果：strict Hit@1 再提升 **+15.79pp / +13.69pp**（上表数字已含此项）。
章节命中数仍是主键——命中章节的成药依然排在未命中的正主之前。

### ⚠️ 复查批踩的两个新坑

**坑 4：只用拼音判定会错——`S草` 差点被标成「茜草」**
`S草` 的拼音是 `Shicao`，我据此标成「茜草」。但它的拉丁名是 `ACHILLEAE HERBA`、
概述写「菊科植物**蓍** Achillea alpina」——正确名是 **蓍草**。而真正的「茜草」
是另一条独立条目（拉丁 `RUBIAE RADIX ET RHIZOMA`）。
标错后库里出现**两个「茜草」**，是靠"同名重复"检查才发现的。
**教训：拼音只是线索，必须用拉丁名/概述二次确认。**

**坑 5：药名层规则跑在正文层规则之前，键要用「原始形态」的字**
原文是 `蔥麻子`（蓖麻子的误认）。我把规则键写成 `蒽麻子`（清洗后的形态），
结果**永远命中不了**——因为 `fix_drug_name`（药名层）先跑，而 `蔥→蒽` 发生在
`clean_text`（正文层）里、后跑。清洗后库里留下了 `蒽麻子`。
**修法：键用原文形态（`蔥麻子`/`菌麻子`），并补一条回归测试断言
「清洗后的药名不应再被任何规则改动」。**

### 顺带修掉的一个系统性 bug：药名里的 `<w:tab/>`

```
原文 XML: <w:r><w:t>策</w:t></w:r><w:r><w:tab/><w:t>巨</w:t></w:r>
```

python-docx 读出 `策\t巨`。而 `clean_entry` 当时只做 `replace(' ', '')`——**去不掉 Tab**；
紧接着 `clean_text` 里的 `re.sub(r'[ \t]+', ' ')` 又把 **Tab 折叠成空格**。
顺序颠倒的结果：库里落成 **`策 巨`**（带空格的药名），精确匹配全部失效。

修法：药名/parent_drug 一律改用 `re.sub(r'\s+', '', ...)`，在 `clean_text` **之前**清干净。

## 七、仍未解决

- **同名重复**：修正后可能出现同名条目（如 `炙黄芪` 与既有条目重名），
  目前不做去重，仅在多条目下竞争排序。
- **拼音字段不可靠**：空 **788** 个、只存拉丁名 **68** 个、疑似只存剂型末音节 **14** 个
  （合计约 35% 不可用）。本次只能拿它做**定性线索**，且已证明**单独用它会出错**
  （见坑 4 `S草`）。要做自动化检测得先修这个字段。
- **剩余低频错字**：`當`(→甾，麦角當醇)、`歸`(→磷/铁/锑，三氯化歸)、`陳`(→晾)、
  `菴`(→莶)、`貓`(→豨) 等，出现次数少（1~6 次）且一字多义，未做处理。
- **`醌` 的变体**：除 `蒽醌` 词组外，仍有零星 `酿/醞/酝` 未覆盖。
- **`土鳖虫（鹰虫）`**：药典别名应为「蟅虫」，但 `蟅` 字在库中无其它佐证，证据不足，暂未改。
- **同名重复 7 组（饮片级）**：`刀豆-饮片`、`小蓟-饮片`、`苍术-饮片`、`禹州漏芦-饮片`、
  `锁阳-饮片`、`豨薟草-饮片`、`稻芽-饮片` 各有 2 个条目（**非本次引入**，属既有数据问题）。
- **1 个由拉丁名段落误生成的假条目**：
  `PEGAEOPHYTIRADIXETRHIZOMA（Hook.f.etThoms.）Marq.etShaw的干燥根和根茎。…`
- **评测集看不见本次改动**：复查批 40 个药名修完后，检索指标 **一格未动**
  （因为测试集里没有这些药的题目）。这是 [docs/11](11_本轮总账.md) 第五节那条结论的又一例证。
