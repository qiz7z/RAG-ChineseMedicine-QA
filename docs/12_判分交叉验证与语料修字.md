# 12 · 判分交叉验证与语料修字

> 2026-09-22（第四篇）。接 [docs/11](11_本轮总账.md)。
> 缘起：缺陷 10（判分收口）之后，项目最重要的诚实数字变成了 **9.45% 幻觉率**——
> 但它由**单一 LLM 判官**产出，而 LLM-as-judge 有一个众所周知的弱点：**自偏好**
> （模型对"自己那种风格的说法"更宽松）。一个没有交叉验证的关键数字是不可信的。
> 本文记录：第二个判官怎么设计、四轮校准暴露了什么、以及**它顺带抓出的一个语料缺陷**。

---

## 一、第二判官的设计：把"判定"变成"可核验的证据"

`GroundingJudge`（第一判官）的问法是："这句话有据吗？请贴标签。"

第二判官 `QuoteVerifiedJudge` 换了一个**机制不同**的问法：

> "对每条论断，从【参考资料】里**逐字抄出**能支撑它的原文片段；抄不出就写 NONE。"

然后由**代码**核验：引文（归一化后）是否真的是来源的子串。

| 情形 | 判定 |
|------|------|
| 抄不出片段（NONE） | unsupported |
| 抄出的片段核验**通过** | supported |
| 抄了但核验**不通过** | **伪造引文**（fabricated），按 unsupported 计并单独计数 |

这个设计把判定建立在**可机械验证的证据**上：

1. **自偏好几乎被消除**——模型必须对具体文本负责，不能笼统地说"资料里提到了"；
2. 产出一个第一判官**给不出的硬信号**：`fabricated_quote_rate`（伪造引文率）；
3. 判定是**确定性**的：同一次引文，谁跑结果都一样。

`verify_quote` 的归一化只处理**表示形式**差异（空白、全角/半角、波浪号、标点），
**不动语义**——改一个字就核验失败，这正是"逐字"的意义。

```python
# 标点不敏感 + 全角归一 + 波浪号统一，但文字必须逐字连续
verify_quote("归脾、肺、心、肾经", "甘、微苦，微温；归脾、肺、心、肾经。")   # True
verify_quote("归脾、肺、心包经",   "甘、微苦，微温；归脾、肺、心、肾经。")   # False（少一个字）
```

**两判官不是替代关系，是夹逼关系**：第二判官量"逐字可核验的下限"（跨句推理才算有据时它会偏严），
第一判官量"语义上界"。两者结合才是对真相的逼近。

## 二、四轮校准：交叉验证立刻暴露的问题

用 `--crosscheck` 对 30 题样本同时跑两判官，对齐 84 条共同论断：

| 轮次 | 论断级一致 | 回答级一致 | 暴露的问题 |
|------|-----------|-----------|-----------|
| 第 1 轮 | 56.4% | 22.2% | **判分不可信** |
| 第 2 轮（过滤非论断 + min_len 8→5） | 69.4% | 51.9% | 框架句/引用行混进分母 |
| 第 3 轮（框架句补「为」尾 + 缺席句过滤） | 87.6% | 75.9% | 拒答句、"未在资料中收录" |
| 第 4 轮（min_len 5→4 + 句尾系词 + 引荐句） | **84.5%** | **88.9%** | 剩余为设计内分歧 |

> 论断级第 4 轮略降是 LLM 采样抖动（每轮回答都不同）；回答级单调上升。
> 关键不是绝对值，而是**剩余分歧是否可解释**——第 4 轮的 13 条分歧逐条看过，
> 全部属于下面三类**设计内分歧**，没有再发现判分器 bug。

**第 1 轮就判了"判分不可信"死刑，剩下的轮次是在修两件事**：

### 1. 非论断污染分母（两判官都受害）

回答里混着大量**不承载事实的句子**，第一判官宽松地判"有据"（拉高有据率），
第二判官因抄不出原文判"无据"（制造假分歧）：

- **框架句**：「根据药典参考资料，人参的性味归经如下」——被冒号/换行截断后独立成句，
  以「如下 / 为 / 是 / 有」收尾，本身无任何可验证内容；
- **引用行**：「[4] 药典2020一部-天麻祛风补片-含量测定」——只是来源标题；
- **检索陈述**：「资料中未收录麻黄的注意事项」——这是关于**检索结果**的陈述，
  不是药品事实论断；引文式判官无法用子串核验"不存在"，硬判必不一致；
- **引荐句**：「如需了解…请参考《中国药典》完整条目」——导航语。

过滤它们之后，第一判官的**论断有据率 95.74% → 92.86%**（同一次运行内对比）：
之前的数字被框架句**虚高**了。这就是交叉验证的第一个直接产出——**不用第二判官定案，
光是"两判官打架"就足以发现分母有污染**。

### 2. `min_len` 校准：两个下限都错了

引文核验有个"过短引文蒙对"的防护下限 `min_len`。实测：

- **8** → 误杀「归脾、肺、心、肾经」(6字)、「置干燥处，防蛀」(6字)——合法短论断；
- **5** → 误杀剂量类「2〜5g」(4字)、「外用适量」(4字)——**剂量恰是最常见的数值论断**；
- **4** → 仍挡住「微温」「防蛀」这类 1~2 字的偶然命中。

> 原则：引文逐字出现在来源里就是**真证据**，下限只需防"极短片段蒙对"。
> 这两个错都是**交叉验证的分歧明细里看出来的**，不是拍脑袋调的。

### 3. 剩余分歧的三类（设计内，保留）

1. **逐字 vs 语义**：`6〜12g`、`归肝、胆、心包经`——模型这次没抄出引文就不算，
   这是第二判官作为"下界"的本性；
2. **contradicted vs unsupported**：`"615g`（应为 6〜15g）——两判官**都标记了问题**，
   只是标签不同，都算抓到；
3. **表格残片**：`主治症状`——4 字表头，已在第 4 轮过滤。

## 三、意外产出：抓出一个语料缺陷（澹 / 洶）

第 3 轮分析时，第二判官对 Q026 给出一个**奇怪的支持**：

```
论断: 用于气虚乏力，食少便澹，中气下陷…
第二判官: supported（引文核验**通过**——来源里真的有「食少便澹」）
```

引文核验通过 = 回答与来源**逐字一致**。那"澹"是谁的错？——**语料的**。

全库排查（这是全文正文，不是药名）：

| 字 | 频次 | 真身 | 证据 |
|----|------|------|------|
| `澹` | 57 | 55 次 **溏** + 2 次 **谵** | 对照组：`溏` 与 `谵` 在全库正文都是 **0 次**——两者的每一次出现都被 OCR 认成了澹 |
| `洶` | 7 | **沟**（孔沟/纵沟/横沟，显微描述） | 「沟」合法出现 375 次，`洶` 从不合法 |

`澹` 是**一字多义**，必须先摘走「谵」再整字归「溏」——顺序颠倒会把
「神昏澹语」错改成「神昏**溏**语」：

```python
(r'澹狂', '谵狂'),   # 清热解毒…痰热谵狂
(r'澹语', '谵语'),   # 热入心包，神昏谵语
(r'澹',   '溏'),     # 其余 55 处：便澹→便溏、五更澹泻、大便澹薄、内无澹心(阿胶珠)
(r'洶',   '沟'),     # 孔洶→孔沟、纵洶→纵沟、横洶→横沟
```

修后：语料 `澹`/`洶` = 0，`溏` 54 + `谵` 3（= 原 57 ✓）。

**这条教训比修字本身重要**：第二判官的引文核验把"回答错"和"语料错"区分开了——
- 引文核验**失败** → 回答自己编的（幻觉）；
- 引文核验**通过**但说法可疑 → 语料本身错（数据缺陷），判分系统**不该**把这笔账算在幻觉头上。

第一判官永远做不了这个区分，因为它只会说"资料里有，所以有据"。

## 四、最终指标（30 题样本，双判官）

| 指标 | 第一判官（语义） | 第二判官（引文核验） |
|------|----------------|-------------------|
| 论断 supported | 78 / 84 | 71 / 84 |
| 论断有据率 | 92.86% | 84.52% |
| 回答级 grounded 一致 | — | 24 / 27（88.9%） |
| 伪造引文 | —（给不出） | **1 条**（被机械捕获） |

- 两判官一致率 84.5%（论断级）/ 88.9%（回答级）——**不再有系统性偏差**；
- 差异集中在"逐字 vs 语义"的夹逼带，逐条可解释；
- 第一判官的对外数字（有据率）从虚高的 95.74% 回落到 **92.86%**。

## 四·补 · 全量重测（109 题）

语料修字后全量重跑（102 题判定成功 / 7 题排除）：

| 指标 | 去污染前（旧分母 1,090 条论断） | 去污染分母（546 条）+ 语料修字 |
|------|------------------------------|------------------------------|
| 幻觉率 | 9.45% | **11.72%**（无据 9.52% + 矛盾 2.20%） |
| 论断有据率 | 90.55% | **88.28%** |
| 回答有据率 | 64.08% | **78.43%** |

**幻觉率上升不是变差**：旧分母约三成是框架句/引用行（几乎全被判"有据"），
把幻觉率**稀释**了——这是"指标会为坏分母说谎"的又一实例。
回答有据率反而大幅上升（64.08%→78.43%），因为"回答级 grounded"要求**所有论断有据**，
去掉那些必判无据的检索陈述（「资料中未收录X」）后，达标回答自然变多。

## 五、产出与用法

```
src/eval/grounding_judge.py   +QuoteVerifiedJudge / verify_quote / _is_non_claim（~170 行）
scripts/run/run_eval.py       +--crosscheck（每题 +1 次 LLM 调用）
tests/test_grounding_judge.py +~50 项（引文核验、非论断过滤、min_len 校准、伪造引文）
tests/test_etl_cleaner.py     +TestDanYanZi（澹/洶 语料修字）
```

```bash
# 日常评测（单判官）
python scripts/run/run_eval.py --mode generation

# 交叉验证（加开第二判官，每题 +1 次 LLM 调用）
python scripts/run/run_eval.py --mode generation --crosscheck
```

## 六、仍未解决

- **引文式判官的偏严**：需要跨句推理才能算有据的论断会被判无据（下界本性）。
  若要进一步收敛，可让判官允许引用**多段来源**（当前一次只看一批拼接资料，已支持 `…` 分段）；
- **`fetch_k` 之外的判分采样**：判分只用 top-5 来源，若答案其实依据了第 6~10 名会误判；
- **横向条件查询 strict 44~56%** 仍是检索最短板（见 [docs/11](11_本轮总账.md) §九）；
- OCR 低频多义错字（`當`/`歸`/`陳`/`菴`/`貓`）与 `醌` 的零星变体仍在（见 [docs/10](10_OCR药品名与异体字纠错.md) §七）。
